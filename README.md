# خدرة شاي

حاسبة تعطيك وزنة الشاي والسكر ومدة الخدرة وعدد البيالات حسب نوع الشاي وكمية الماء.
الموقع: https://khadra-t.netlify.app/

## هيكل المشروع

| الملف | الدور |
| --- | --- |
| `index.html` | هيكل الصفحة: شاشات الخطوات (الشاي ← الماء ← الذوق ← الوصفة)، المفضلة، آخر الخدرات |
| `assets/data.js` | كتالوج الشاي: المقادير لكل 1 لتر حسب المذاق، ومدة الخدرة |
| `assets/core.js` | المنطق: الحساب والتقريب، التحقق من المدخلات، نص المشاركة، صيغ الحفظ |
| `assets/app.js` | الواجهة: التنقل بين الخطوات وعرض الحالة، ولا يحسب شيء بنفسه |
| `assets/app.css` | التصميم الليلي (عنابي بلون الشاي وذهبي، خط عارف رقعة للعناوين) |
| `img/teas/` | صور العلب على الخلفية العنابية الموحدة (560px) |
| `img/tins/` | العلب مقصوصة بدون خلفية لشاشة الوصفة |
| `fonts/` | خط ثمانية بصيغة WOFF2 (ملفات OTF الأصلية احتياط) |
| `visit-notification.js`, `netlify/functions/visit.mjs` | تنبيه الزيارات عبر تيليجرام |

## إضافة نوع شاي

أضف سطر في `SIMPLE_TEAS` داخل `assets/data.js` (أو عنصر داخل `BRANDED_TEAS` إذا البراند له أكثر من نوع ورق)،
وحط الصورة الأصلية في الجذر، ثم جهّز منها نسختين بنفس الاسم: العلبة مقصوصة في `img/tins/`
والعلبة على الخلفية الموحدة في `img/teas/`. إذا ما وجدت النسخ الجديدة تظهر الصورة الأصلية تلقائياً.

## الحفظ على الجهاز

نفس مفاتيح وصيغ النسخة السابقة، فمفضلة المستخدمين وسجلهم تبقى بعد التحديث:
`khadra-t:last-selection:v1`، `khadra-t:favorites:v1`، `khadra-t:recent-brews:v1`.

## الاختبارات

```sh
node tests/core-parity.cjs     # يطابق الحساب والحفظ مع النسخة المعتمدة السابقة حرفياً
node tests/ui.mjs              # اختبار متصفح حقيقي (يحتاج Playwright، ويتخطى إذا غير موجود)
node tests/visit-notification.mjs
node tests/visitor-identity.mjs
```
